CLO 렌더링 기초: 카메라·조명·재질부터 이미지와 영상 출력까지

2026.10.06
CLOCLO 2026V-RayRenderingCameraLighting수업자료

CLO 렌더링을 처음 시작하는 학생을 위한 단계별 매뉴얼입니다. 렌더 전 의상 점검, V-Ray Render 창, 카메라와 조명, 재질 확인, 이미지·턴테이블·애니메이션 출력, 노이즈와 GPU 오류 해결까지 한 흐름으로 익힙니다.

CLO의 3D창에서 의상이 잘 보인다고 바로 좋은 렌더가 만들어지는 것은 아닙니다. 렌더링은 완성된 의상에 카메라, 조명, 배경과 출력 설정을 더해 한 장의 이미지 또는 영상으로 계산하는 과정입니다. 이 매뉴얼은 처음부터 모든 값을 외우는 것이 아니라 ① 의상 상태를 먼저 정리하고 ② Interactive Render로 빠르게 확인하고 ③ 카메라·조명·재질을 한 항목씩 수정한 뒤 ④ 작은 테스트 이미지를 뽑고 ⑤ 마지막에 최종 해상도로 출력하는 순서를 익히는 데 목적이 있습니다.

이번 매뉴얼에서 완성할 결과

□ Render 창을 열고 Interactive Render와 Final Render의 차이를 설명할 수 있습니다. □ 카메라 구도와 노출을 조절할 수 있습니다. □ Dome Light와 Rectangle Light의 역할을 구분할 수 있습니다. □ 원단의 Base Color·Normal·Roughness·Metalness·Opacity를 확인할 수 있습니다. □ 테스트 렌더와 최종 렌더의 해상도·품질을 다르게 설정할 수 있습니다. □ 정지 이미지, 여러 시점, Turntable과 Animation 출력 방법을 구분할 수 있습니다. □ 노이즈, 과노출, 투명 배경과 GPU 오류가 생겼을 때 확인 순서를 알고 있습니다.

먼저 작업 파일과 출력 폴더를 나눕니다

렌더 설정을 시작하기 전에 ZPRJ를 새 버전으로 저장합니다. 예: KHU_이름_의상명_render_v01.zprj. 원본 제작 파일을 그대로 덮어쓰지 않으면 렌더용 포즈·조명·카메라를 바꾼 뒤에도 이전 상태로 돌아갈 수 있습니다. 프로젝트 폴더 안에는 Render_Test와 Render_Final 폴더를 따로 만듭니다. 테스트 이미지는 test_001.png처럼 저장하고, 최종 결과는 final_front_v01.png·final_back_v01.png처럼 시점과 버전을 파일명에 기록합니다. Turntable이나 Animation은 프레임이 많이 생성될 수 있으므로 각각 별도 폴더를 사용합니다.

1. 3D창, Quality Render와 V-Ray Render의 차이

3D창은 패턴 제작과 시뮬레이션을 빠르게 확인하는 작업 화면입니다. File의 Snapshot이나 Video Capture는 이 작업 화면을 기록하는 가벼운 출력이고, 최종 V-Ray Render와는 조명·반사·그림자 품질이 다릅니다. Render → Quality Render (3D Window)는 3D창의 표시 품질을 높여 빠르게 확인하는 기능입니다. Render → Render는 별도의 V-Ray Render 창을 열어 카메라, 조명, 재질과 출력 설정을 계산합니다. 과제용 최종 이미지에서는 Render 창의 Final Render를 기준으로 합니다. AI Studio 또는 AI Render 기능은 렌더 이후 얼굴이나 배경을 보조하는 확장 기능입니다. 원단 무늬와 봉제 디테일이 달라질 수 있으므로 기본 렌더를 먼저 완성하고 원본과 비교할 수 있을 때만 사용합니다.

2. 렌더 전에 의상 상태를 먼저 점검합니다

1. Simulation을 켜 의상이 안정된 뒤 멈춥니다. 흔들리거나 폭발한 상태로 렌더를 시작하지 않습니다. 2. 정면·측면·후면에서 아바타 관통, 겹친 옷의 충돌, 뒤집힌 면과 봉제 오류를 확인합니다. 3. 최종 포즈에서 겨드랑이, 목, 허리, 무릎과 손 주변을 확대합니다. 카메라에서 안 보일 것 같아도 그림자나 반사에 나타날 수 있습니다. 4. 패턴의 Add’l Thickness - Rendering과 원단 두께가 과하지 않은지 확인합니다. 충돌 두께와 렌더 두께는 서로 다른 값입니다. 5. 필요한 경우 Hi-Res Garment를 사용하고 다시 시뮬레이션합니다. 모든 패턴의 Particle Distance를 무조건 아주 낮게 만들지 말고, 주름과 실루엣이 중요한 부분부터 단계적으로 높입니다. 6. 불필요한 아바타, 소품, 테스트 패턴과 숨은 오브젝트를 정리합니다. 7. ZPRJ를 저장한 뒤 Render 창을 엽니다. 렌더러는 패턴 오류를 고쳐 주지 않습니다. 해상도와 품질을 올리기 전에 의상 자체의 형태와 관통을 먼저 해결해야 합니다.

3. 원단 물성과 렌더 재질을 구분합니다

Physical Property는 의상이 늘어나고 접히고 흔들리는 방식을 결정합니다. Render Material은 빛을 받았을 때 보이는 색, 광택, 요철과 투명도를 결정합니다. 실루엣이 잘못된 문제를 Roughness로 고칠 수 없고, 플라스틱처럼 보이는 문제를 Bending 값으로 고칠 수 없습니다. • Base Color / Map: 원단의 기본 색과 프린트입니다. • Normal Map / Intensity: 메쉬를 직접 움직이지 않고 미세한 요철의 빛 반응을 만듭니다. • Roughness: 낮을수록 반사가 선명하고 매끈하며, 높을수록 무광에 가깝습니다. • Reflection: 표면에 보이는 반사량입니다. Roughness와 함께 확인합니다. • Metalness: 금속 재질에 사용합니다. 일반 천과 피부에는 보통 낮게 유지합니다. • Opacity / Map: 레이스, 망사, 얇은 투명 소재의 투명도를 조절합니다. • Displacement: 실제 렌더 메쉬를 밀어 요철을 만듭니다. 너무 높은 값과 너무 촘촘한 메쉬는 렌더 시간을 크게 늘립니다. • Fur: 털의 길이·밀도·방향이 실루엣과 렌더 시간을 크게 바꿉니다. 최종 품질 전에 작은 테스트 영역으로 확인합니다. 재질을 수정할 때는 한 번에 여러 값을 바꾸지 않습니다. Interactive Render를 켜고 Roughness 또는 Normal처럼 한 항목씩 바꿔 전후 차이를 비교합니다.

4. V-Ray Render 창을 열고 미리보기 시작하기

1. Main Menu → Render → Render를 선택합니다. Display → Window → Render에서도 열 수 있습니다. 2. Render 창 가운데를 클릭하거나 Toolbar의 Interactive Render를 누릅니다. 3. 잠시 기다리면 현재 3D창의 의상과 아바타가 렌더됩니다. 첫 실행은 재질과 텍스처를 읽느라 시간이 걸릴 수 있습니다. 4. Interactive Render가 켜진 동안 재질이나 조명을 바꾸면 결과가 다시 계산됩니다. 화면이 계속 흐릿한 것은 계산 중일 수 있습니다. 5. 계산을 잠시 멈출 때는 Stop Render를 누릅니다. 6. 확정된 결과를 파일로 저장할 때만 Final Render (Image/Video)를 사용합니다. Final Render는 Image/Video Properties, Camera, Light와 Render Properties의 설정을 기준으로 계산하고 저장합니다. Interactive Render는 빠른 비교용이고 Final Render는 실제 파일 출력용입니다. Interactive 화면을 캡처해서 최종 결과로 제출하지 않습니다.

Render 화면이 자꾸 움직일 때: Lock Camera

Render Toolbar의 Lock Camera를 켜면 Render 화면의 카메라가 고정됩니다. 이후 3D창을 회전해 의상 뒷면이나 재질을 확인해도 렌더 구도는 움직이지 않습니다. 구도를 다시 잡고 싶을 때는 Lock Camera를 끄고 3D창의 시점을 조절한 뒤 다시 켭니다. 초보자는 재질을 고치다가 카메라까지 같이 움직이는 실수가 많으므로, 구도가 정해지면 Lock Camera 상태를 먼저 확인합니다.

5. 카메라 구도와 노출 설정하기

Camera Properties는 Render 창 Toolbar, Object Browser → Scene → Environment → Camera → Default Camera 또는 3D창 우클릭 메뉴에서 열 수 있습니다. • Lens / Field of View: 화면에 보이는 범위와 원근감을 조절합니다. 너무 넓으면 얼굴과 팔다리가 왜곡되고, 너무 좁으면 카메라를 멀리 옮겨야 합니다. • Spherical View: 아바타를 중심으로 거리와 수평·수직 각도를 조절하기 편합니다. • Absolute View: 수평·수직 이동을 기준으로 구도를 잡을 때 사용합니다. • Near / Far Clipping Plane: 카메라가 보여 주는 가장 가까운 거리와 먼 거리입니다. 의상 일부가 잘리면 구도와 함께 이 값을 확인합니다. • Exposure: 전체 밝기의 기준입니다. 공식 매뉴얼은 조명 밝기를 무작정 올리기보다 Camera Exposure를 이용해 노출을 조절하도록 안내합니다. • ISO: 높일수록 밝아집니다. • F-Number: 낮을수록 밝아지고 얕은 심도를 만들기 쉽습니다. • Shutter Speed: 값이 바뀌면 노출과 움직임 표현에 영향을 줍니다. 처음에는 Default Camera와 기본 Exposure에서 시작합니다. 화면이 어둡다고 Exposure, ISO, 조명 Intensity를 동시에 바꾸지 말고 Camera Exposure를 먼저 조금씩 조정합니다.

6. 자주 쓰는 시점은 Custom View로 저장합니다

1. 3D창에서 정면 전신 구도를 만듭니다. 2. 3D창 배경을 우클릭하고 Custom View를 엽니다. 3. Add Current Viewpoint를 눌러 현재 시점을 저장합니다. 4. Front_Full, Back_Full, Detail_Top처럼 이름을 바꿉니다. 5. 필요한 정면·후면·디테일 시점을 반복 저장합니다. 6. View Only는 카메라 위치만 불러오고, View with Display Settings는 저장 당시의 표시 상태도 함께 불러옵니다. 7. 다른 프로젝트에서도 사용할 시점은 ZCMR 파일로 Save합니다. Image/Video Properties의 Custom View를 이용하면 저장한 여러 시점을 같은 크기와 설정으로 출력할 수 있습니다. 시점마다 카메라를 손으로 다시 맞추는 것보다 결과 비교가 정확합니다.

7. 조명은 적은 수로 시작합니다

Light Properties에서 조명 Preset을 선택하거나 각 Light의 Intensity·Color·Activate를 조절할 수 있습니다. 조명이 많아질수록 계산이 느려지고 어떤 조명이 문제인지 찾기 어려워집니다. • Dome Light: HDR Environment Map으로 장면 전체를 감싸는 기본 환경광입니다. 초보자는 Studio Low Contrast 같은 기본 스튜디오 계열에서 시작합니다. • Rectangle Light: 큰 면광원입니다. 의상의 형태와 주름을 보여 주는 Key Light로 사용하기 좋습니다. Width와 Height가 커지면 그림자가 부드러워집니다. • Sphere Light: 전구처럼 주변을 밝힙니다. • Spot Light: 특정 부분을 원뿔 형태로 비춥니다. Cone Angle, Penumbra와 Shadow Radius로 범위와 경계를 조절합니다. • IES Light: 실제 조명 기구의 배광 데이터를 사용합니다. 첫 실습에서는 필수가 아닙니다. • Ground Shadow: 전신 렌더에서 발이 바닥에 붙어 보이도록 바닥 그림자를 표시합니다. 첫 설정은 Dome Light 하나로 시작하고, 얼굴이나 의상 전면이 평평하면 Rectangle Light 한 개를 Key Light로 추가합니다. Rectangle Light를 사용할 때는 강한 밝은 점이 없는 HDRI를 선택하면 이중으로 강한 주광이 생기는 것을 줄일 수 있습니다.

조명 수정 순서

1. Dome Light만 켜고 기본 밝기와 그림자를 확인합니다. 2. 카메라 Exposure로 전체 밝기를 먼저 맞춥니다. 3. 의상 형태가 평평할 때 Rectangle Light를 하나 추가합니다. 4. Intensity보다 먼저 조명의 위치와 각도를 움직여 주름에 명암이 생기는지 확인합니다. 5. 흰옷의 디테일이 날아가면 조명 또는 Exposure를 낮춥니다. 검은옷의 주름이 사라지면 정면이 아닌 측면에서 부드러운 Key Light를 추가합니다. 6. 각 단계마다 Interactive Render가 정리될 때까지 기다리고 비교 이미지를 남깁니다. 빛을 많이 추가하는 것이 좋은 조명은 아닙니다. 소재의 광택, 주름과 실루엣이 구분되는지가 기준입니다.

8. Image/Video Properties 설정하기

Render Toolbar의 Image/Video Properties에서 무엇을 어떤 크기로 저장할지 정합니다. • Image/Video: Image, Turntable 또는 Animation 등 출력 종류를 선택합니다. 버전에 따라 Turntable Images처럼 표시될 수 있습니다. • Viewpoint: Current View는 현재 카메라 한 장, Custom View는 저장한 여러 시점을 사용합니다. • Orientation: Portrait는 세로, Landscape는 가로입니다. • Width / Height: 최종 픽셀 크기입니다. Maintain Ratio를 켜면 가로세로 비율이 유지됩니다. • Resolution (ppi): 인쇄용 해상도 정보입니다. 화면 제출에서는 우선 실제 Width와 Height 픽셀을 확인합니다. • Background: Color, Texture 또는 Transparent를 선택합니다. • Save Path / File Name: 저장 위치와 파일명을 지정합니다. • Format: 일반 과제는 PNG를 권장합니다. PNG는 손실 압축이 없고 투명 배경의 알파 채널을 저장할 수 있습니다. JPEG는 파일이 작지만 반복 저장 시 품질이 손실될 수 있습니다. 수업용 예시는 테스트 800×1200px, 최종 1600×2400px처럼 같은 비율을 유지합니다. 실제 과제 규격이 있으면 과제의 픽셀 크기를 우선합니다.

투명 배경을 사용할 때

1. Background를 Transparent로 설정합니다. 2. 알파 채널을 지원하는 PNG 형식을 선택합니다. 3. Final Render를 실행한 뒤 저장된 파일을 Photoshop처럼 투명 배경을 확인할 수 있는 프로그램에서 엽니다. Render 미리보기의 배경색만 보고 실패했다고 판단하지 않습니다. 4. 바닥 그림자가 필요하면 투명 배경과 Ground Shadow가 결과에 어떻게 저장되는지 작은 이미지로 먼저 시험합니다. 5. 영상 형식은 투명도를 지원하지 않거나 옵션이 제한될 수 있습니다. 투명 영상이 필요하면 PNG 이미지 시퀀스로 출력한 뒤 편집 프로그램에서 합성하는 방법을 사용합니다.

9. Render Properties: 속도와 품질 정하기

• Render Engine — CPU는 기본 선택이며 그래픽카드 조건과 관계없이 사용할 수 있습니다. Windows에서 NVIDIA GPU를 사용할 수 있으면 GPU (CUDA)가 보통 빠릅니다. 사용할 수 없는 엔진은 목록에 없거나 잠길 수 있습니다. • CPU Supporting — GPU (CUDA)와 CPU를 함께 사용할지 정합니다. 다른 작업을 병행해야 하면 시스템 반응을 확인합니다. • Low GPU Priority — 렌더보다 다른 GPU 작업을 우선할 때 사용합니다. • Noise Threshold — 낮을수록 깨끗하지만 오래 걸립니다. 기본 시작값은 0.050입니다. 처음부터 0.001처럼 아주 낮게 설정하지 않습니다. • Max Render Time — 한 장에 사용할 최대 시간입니다. 시간에 도달하면 해당 상태에서 마무리됩니다. • Light / Material Quality — Low, Medium, High, Very High 순으로 품질과 시간이 증가합니다. 흰 퍼나 반사 재질, 복잡한 스튜디오 환경은 더 높은 품질이 필요할 수 있습니다. 초보자 시작값은 Noise Threshold 0.050, Max Render Time 20분 이내, Light와 Material Quality Medium입니다. 먼저 작은 테스트 이미지를 출력해 실제 소요 시간을 확인한 뒤 필요한 항목만 높입니다.

10. 첫 번째 정지 이미지 출력 순서

1. Image/Video를 Image, Viewpoint를 Current View로 설정합니다. 2. 테스트 크기를 800×1200px처럼 작게 지정하고 PNG를 선택합니다. 3. 배경은 단색 또는 투명을 선택합니다. 4. Render Engine을 확인하고 Noise Threshold 0.050, Light·Material Medium으로 시작합니다. 5. Interactive Render에서 구도, 밝기, 그림자와 재질을 확인합니다. 6. 문제가 없으면 Stop Render를 누른 뒤 Final Render를 실행합니다. 7. 저장된 PNG를 실제 크기로 열어 얼굴, 의상 테두리, 봉제선, 주름, 투명 재질과 노이즈를 확인합니다. 8. 수정이 필요하면 한 항목만 바꾸고 test_002.png로 다시 출력합니다. 9. 테스트가 통과하면 Width·Height를 최종 크기로 바꾸고 필요한 경우 Light 또는 Material Quality만 한 단계 올립니다. 10. Final Render를 실행하고 final_front_v01.png로 저장합니다. 작은 테스트 한 장을 생략하고 바로 고해상도 Turntable이나 Animation을 렌더하면 잘못된 조명 한 개 때문에 수십 장을 다시 계산할 수 있습니다.

11. 정면·후면·디테일을 같은 설정으로 출력하기

1. Custom View에 Front_Full, Back_Full, Detail_Top 등을 저장합니다. 2. Image/Video Properties에서 Image와 Custom View를 선택합니다. 3. 출력할 시점을 체크합니다. 4. 모든 시점에 같은 Width, Height, 배경과 품질을 적용합니다. 5. 각 시점에서 의상이 프레임 밖으로 잘리지 않는지 Interactive Render로 확인합니다. 6. Final Render를 실행한 뒤 각 파일의 시점 이름과 순서를 확인합니다. 여러 시점을 일괄 출력하기 전에 한 시점만 테스트합니다. 잘못된 노출이나 재질을 여러 장에 반복해서 렌더하지 않도록 하는 것이 핵심입니다.

12. Turntable 렌더 만들기

Turntable은 아바타와 의상을 중심으로 카메라가 회전해 앞·옆·뒤를 보여 주는 출력입니다. File → Video Capture → Turntable은 3D 작업창을 빠르게 녹화하는 방식이고, Render 창의 Turntable은 V-Ray 조명과 재질을 계산하는 방식입니다. 제출 목적에 맞게 구분합니다. 1. 먼저 같은 카메라와 조명으로 정지 이미지 한 장을 Final Render합니다. 2. Image/Video를 Turntable 또는 Turntable Images로 선택합니다. 3. 회전 방향, 각도, Image Count와 FPS를 설정합니다. Image Count가 많을수록 움직임은 부드럽지만 총 렌더 시간이 늘어납니다. 4. Save Video가 필요한 경우 켜고 지원 형식을 선택합니다. 편집과 오류 복구가 중요하면 이미지 시퀀스를 함께 보관합니다. 5. 저장 폴더를 Turntable_v01처럼 별도로 지정합니다. 6. 낮은 해상도와 품질로 짧은 테스트를 먼저 실행해 중심축, 프레임 잘림과 그림자를 확인합니다. 7. 테스트 통과 후 최종 크기와 품질로 다시 출력합니다. 예상 시간은 ‘한 프레임 렌더 시간 × Image Count’에 가깝습니다. 한 장에 2분이고 120장이면 계산만 약 240분이므로 수업 시간과 컴퓨터 사양에 맞게 Image Count와 품질을 정합니다.

13. Animation 렌더 만들기

Animation 렌더를 시작하기 전에 Animation Editor에서 아바타 모션과 의상 시뮬레이션이 Record되어 있어야 합니다. Play만 해서 아바타가 움직이는 상태와 의상 애니메이션이 기록된 상태는 다릅니다. 1. Animation Editor에서 시작·끝 프레임, FPS와 의상 관통을 확인합니다. 2. 문제가 없는 짧은 구간을 Selected Region으로 정합니다. 처음부터 Entire Region 전체를 렌더하지 않습니다. 3. Render 창에서 Image/Video를 Animation으로 선택합니다. 4. Entire Region 또는 Selected Region을 선택하고 FPS를 확인합니다. 5. Save Video를 사용할지, 프레임 이미지를 저장할지 정합니다. 후반 편집과 중간 실패 복구가 필요하면 PNG 이미지 시퀀스가 안전합니다. 6. 낮은 해상도·Medium 품질로 10–30프레임을 먼저 출력합니다. 7. 의상과 아바타의 위치, 모션 속도, 그림자 깜빡임과 카메라 잘림을 확인합니다. 8. 테스트가 통과한 뒤 전체 구간과 최종 해상도로 출력합니다. 애니메이션 중 한 프레임에서 관통이 생기면 렌더 품질 문제가 아닙니다. Animation Editor에서 해당 프레임 전후의 시뮬레이션을 수정하고 다시 기록해야 합니다.

14. 여러 컬러웨이를 렌더할 때

컬러웨이는 색만 다른 것처럼 보여도 밝기와 재질 반응이 달라집니다. 흰색은 과노출로 디테일이 날아가기 쉽고, 검은색은 주름이 묻히기 쉽습니다. 금속과 유리는 같은 조명에서도 반사가 크게 달라집니다. 공통 카메라와 조명을 먼저 고정하고 각 컬러웨이를 한 장씩 테스트합니다. 전체 밝기를 컬러마다 크게 바꾸기보다 원단 Base Color, Roughness와 필요한 보조광을 점검합니다. 출력 폴더와 파일명에 color01_black, color02_ivory처럼 컬러명을 기록해 덮어쓰지 않습니다.

자주 생기는 문제와 확인 순서

화면이 너무 어둡거나 검게 보이면 Light의 Activate, Dome Light, Camera Exposure와 카메라가 오브젝트를 향하는지 확인합니다. 흰색 부분이 날아가면 조명을 더 추가하지 말고 Exposure와 Key Light Intensity를 낮춥니다. 검은 원단의 주름이 사라지면 옆 방향의 부드러운 Rectangle Light와 Roughness를 확인합니다. 이미지가 계속 거칠면 Interactive 계산이 끝났는지 확인하고, Final Render에서 Max Render Time을 늘리거나 Noise Threshold를 조금 낮춥니다. 해상도·Light Quality·Material Quality를 한꺼번에 올리지 않습니다. 원단이 플라스틱처럼 보이면 Metalness가 불필요하게 높지 않은지, Roughness가 너무 낮지 않은지, Normal 강도가 과하지 않은지 확인합니다. 의상이 공중에 뜬 것처럼 보이면 Ground Shadow와 바닥 위치를 확인합니다. 발과 바닥 사이의 실제 거리도 3D창에서 확인합니다. 옷 일부가 잘리면 카메라 구도, 이미지 비율과 Near/Far Clipping Plane을 확인합니다. 투명 배경이 흰색으로 보이면 PNG 형식, Background Transparent와 최종 파일의 알파 채널을 확인합니다. 미리보기 배경만 보고 판단하지 않습니다. GPU 렌더가 멈추거나 메모리 오류가 나면 다른 GPU 프로그램을 닫고, 이미지 크기·퍼·Displacement·재질 품질을 낮춰 테스트합니다. 계속 실패하면 CPU Engine으로 바꿉니다. Turntable 또는 Animation이 첫 장에서 멈추면 Image/Video 종류, 저장 폴더 권한, Image Count·Frame Range와 남은 저장 공간을 확인하고 정지 이미지 한 장이 정상 렌더되는지 먼저 시험합니다.

품질을 올릴 때 지켜야 할 순서

1. 의상 관통과 실루엣을 수정합니다. 2. 카메라 구도와 이미지 비율을 확정합니다. 3. Dome Light와 Exposure로 전체 밝기를 맞춥니다. 4. 필요한 경우 Rectangle Key Light 하나를 추가합니다. 5. Base Color, Roughness, Normal과 Metalness를 점검합니다. 6. 작은 크기·Medium 품질로 Final Render 한 장을 확인합니다. 7. 노이즈가 문제일 때만 Max Render Time 또는 Noise Threshold를 조절합니다. 8. 퍼·반사·복잡한 환경에 필요할 때만 Light 또는 Material Quality를 높입니다. 9. 마지막에 최종 Width와 Height로 출력합니다. 이 순서를 지키면 해상도를 크게 만든 뒤 다시 처음부터 렌더하는 일을 줄일 수 있습니다.
