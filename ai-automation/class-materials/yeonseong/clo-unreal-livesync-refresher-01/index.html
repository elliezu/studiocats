CLO–Unreal LiveSync 다시 연결하기 — 런웨이 복습 ①

2026.08.30
CLOUnreal EngineLiveSyncVirtual Runway수업자료

방학 뒤 다시 시작하는 학생을 위한 CLO–Unreal LiveSync 복습입니다. 버전 확인부터 연결, Update, 포즈·애니메이션 전송, Unreal Asset 저장과 오류 점검까지 한 번에 훑습니다.

이번 복습의 목표는 CLO에서 완성한 의상, CLO 기본 아바타, 정지 포즈 또는 애니메이션을 Unreal Engine으로 다시 연결하는 것입니다. 복잡한 재질 수정이나 Chaos Cloth 제작보다 ‘연결 → 확인 → 저장’의 기본 순서를 되찾는 데 집중합니다. LiveSync는 CLO와 Unreal Editor 사이를 연결해 반복적인 파일 Export와 Import를 줄여 주는 도구입니다. CLO에서 의상이나 포즈를 수정한 뒤 Unreal의 Update를 누르면 같은 연결을 통해 결과를 다시 확인할 수 있습니다.

이번 복습에서 성공해야 하는 것

□ CLO와 Unreal을 한 개씩 실행하고 LiveSync 연결 상태를 초록색으로 만듭니다. □ 의상과 CLO 아바타가 Unreal Viewport에 나타납니다. □ CLO의 정지 포즈 또는 애니메이션이 Unreal에서 동일하게 보입니다. □ Update와 Save의 차이를 설명할 수 있습니다. □ 아바타와 가먼트의 Geometry Cache Asset 위치를 찾을 수 있습니다. □ LiveSync는 Level Sequence를 완성해 주는 단계가 아니며, Sequencer 구성은 직접 해야 한다는 것을 이해합니다. □ 연결이 끊겼을 때 버전, 실행 개수, 설정과 플러그인을 순서대로 확인할 수 있습니다.

1. 시작 전에 버전과 프로젝트를 확인합니다

LiveSync는 CLO, Unreal Engine, LiveSync 플러그인의 지원 버전이 맞아야 작동합니다. 수업실 PC에서는 임의로 Unreal 버전이나 LiveSync 플러그인을 업데이트하지 않고, 수업에서 지정한 조합을 그대로 사용합니다. CLO LiveSync 2.2.2 공식 호환표는 Unreal Engine 5.5–5.7과 CLO 2026.0 이상 조합을 안내합니다. 다른 버전을 사용하는 경우 공식 Version Archive에서 정확한 조합을 먼저 확인합니다. Unreal 프로젝트의 DirectX 11/12 설정도 중간에 임의로 바꾸지 않습니다. 공식 문서는 LiveSync로 가져온 Asset이 RHI 설정을 오갈 때 열리지 않을 수 있다고 안내합니다. 수업용 프로젝트 설정을 유지합니다.

2. CLO 원본 프로젝트를 먼저 정리합니다

1. CLO 프로젝트를 먼저 저장합니다. 파일명은 영문과 숫자를 중심으로 간단하게 작성합니다. 저장하지 않은 프로젝트는 Unreal에 Save할 때 상위 폴더가 Untitled로 만들어질 수 있습니다. 2. 의상 시뮬레이션을 안정된 상태에서 멈춥니다. 관통이나 폭발 상태를 그대로 전송하지 않습니다. 3. 사용할 아바타와 의상만 남기고 필요 없는 테스트 오브젝트는 숨기거나 정리합니다. 4. 정지 화보용이면 원하는 포즈를 적용합니다. 런웨이용이면 Animation Editor에서 사용할 모션, 시작 프레임과 끝 프레임을 확인합니다. 5. Metal, Leather, 투명 소재 등 중요한 재질이 CLO에서 정상인지 확인합니다. Unreal에서는 렌더러 차이로 완전히 동일하지 않을 수 있지만, Base Color·Normal·Roughness·Metallic·Reflection·Opacity 맵이 LiveSync 대상입니다. 6. 프로젝트를 다시 저장합니다.

3. Unreal 프로젝트와 플러그인을 확인합니다

1. 수업용 Unreal 프로젝트를 엽니다. LiveSync 설정이 포함된 프로젝트에서는 새 프로젝트를 임의로 만들지 않습니다. 2. Edit → Plugins에서 CLO/MD LiveSync와 Substance 3D for Unreal Engine이 활성화되어 있는지 확인합니다. 3. 플러그인을 켠 뒤 Restart 안내가 나오면 프로젝트를 저장하고 Unreal Editor를 다시 시작합니다. 4. LiveSync Mode를 처음 열 때 Missing Project Settings 안내가 나오면 수업 지시에 따라 Enable Missing을 누르고 다시 시작합니다. 5. CLO 또는 Unreal을 여러 개 실행하지 않습니다. LiveSync는 CLO 한 개와 Unreal Editor 한 개의 연결을 기준으로 작동합니다. 6. 컴퓨터 이름에 한글이나 특수문자가 포함된 환경에서는 연결 문제가 생길 수 있으므로 수업실 PC 이름을 임의로 변경하지 말고 담당자에게 알립니다.

4. CLO/MD LiveSync Mode를 엽니다

1. CLO와 Unreal Editor를 모두 실행합니다. 2. Unreal 왼쪽 상단 Selection Mode 메뉴에서 CLO/MD LiveSync를 선택합니다. 단축키는 Shift+9입니다. 3. LiveSync 탭의 Connection Status를 확인합니다. 초록색이면 연결됨, 빨간색이면 연결되지 않은 상태입니다. 4. 빨간색일 때는 CLO 창으로 이동해 패턴을 한 번 클릭하거나 Viewport를 조작한 뒤 다시 확인합니다. 5. 그래도 빨간색이면 CLO의 LiveSync 사용 설정, 실행 중인 프로그램 개수와 버전 조합을 확인한 뒤 CLO를 다시 시작합니다. 예전 버전 자료의 Window → CLO/MD LiveSync Editor와 현재 LiveSync 2의 Selection Mode 방식이 다를 수 있습니다. 이 수업에서는 Unreal 화면에 보이는 최신 LiveSync Mode를 기준으로 진행합니다.

5. 무엇을 가져올지 선택합니다

Garment의 Include Garment를 켜면 CLO 의상을 가져옵니다. Single Object는 의상 조각을 하나로 묶고, Multiple Object는 분리된 상태를 유지합니다. Thin은 CLO의 Textured Surface, Thick은 Thick Textured Surface에 대응합니다. Avatar의 Include Avatar를 켜면 CLO 아바타를 가져옵니다. LiveSync에는 Joint와 Cache 방식이 모두 있지만, 이번 런웨이 수업에서는 아바타와 가먼트의 재생 결과를 동일한 방식으로 관리하기 위해 둘 다 Cache Animation으로 저장하는 흐름을 사용합니다. Scene and Props는 CLO 장면의 소품을 함께 가져올 때만 켭니다. 수업에서 사용하지 않는 소품까지 가져오면 Outliner와 Content Browser가 복잡해집니다. 정지 확인만 할 때는 Animation 옵션을 끌 수 있습니다. 런웨이 모션을 가져올 때는 Garment의 Include Cache Animation과 Avatar Animation의 Cache를 사용합니다. Joint Animation은 기능 확인용 선택지이며 수업 기본 경로로 사용하지 않습니다.

포즈와 애니메이션을 가져오는 기준

정지 화보용 포즈는 CLO에서 포즈를 적용한 현재 상태를 Update해 먼저 확인합니다. 시간에 따라 움직이는 데이터가 필요하지 않다면 Animation 옵션을 끈 상태로 연결을 점검할 수 있습니다. 런웨이 애니메이션은 CLO Animation Editor에서 모션이 실제로 재생되는지 먼저 확인합니다. 수업용 저장에서는 Garment의 Include Cache Animation과 Avatar Animation의 Cache를 사용해 아바타와 가먼트를 각각 Geometry Cache로 만듭니다. 이후 학생이 Unreal에서 Level Sequence를 직접 만들고 두 Geometry Cache Track을 같은 시작 프레임에 배치합니다. Joint Animation을 선택하면 Skeletal Mesh와 Animation Sequence 방식으로 들어올 수 있지만, 아바타 자세·루트 위치·의상과의 동기화가 수업 결과와 다르게 보일 가능성을 아직 실제 프로젝트에서 재검증하지 않았습니다. 따라서 기능은 소개만 하고 수업 기본 경로에서는 제외합니다. Play Region은 CLO Animation Editor의 Start/End Frame만 사용하고, Entire Region은 전체 애니메이션을 사용합니다. Cache 방식에서도 CLO와 Sequencer의 FPS와 시작·끝 프레임을 동일하게 맞추는 것이 우선입니다.

6. Update로 Unreal Viewport에서 먼저 확인합니다

1. Include Garment와 Include Avatar를 확인합니다. 2. LiveSync 탭의 Update를 누릅니다. 3. Unreal Viewport에 UsdStageActor가 생성되고 CLO 의상과 아바타가 나타나는지 기다립니다. 첫 전송은 Shader Compile 때문에 시간이 걸릴 수 있습니다. 4. 정면과 측면에서 크기, 바닥 위치, 포즈와 의상 관통을 확인합니다. 5. 재질이 누락되지 않았는지 확인합니다. 투명 재질이 이상하면 Override Transparent Blend Mode의 Translucent와 Opacity Mask 중 수업 재질에 맞는 방식을 확인합니다. 6. CLO에서 작은 수정 후 저장하고 Unreal의 Update를 다시 눌러 변화가 반영되는지 확인합니다. Update는 연결된 장면을 임시로 확인하고 갱신하는 단계입니다. 이때 생성된 UsdStageActor만 보고 Asset 저장이 끝났다고 생각하지 않습니다.

7. Save로 Unreal Asset을 만듭니다

1. Update 결과가 정상일 때 LiveSync 탭의 Save를 누릅니다. 2. 저장할 의상, 아바타, 재질과 애니메이션 Asset을 선택합니다. 3. Content Browser에서 수업용 폴더를 지정합니다. 예: Content/Students/이름/LiveSync. 4. 저장이 끝나면 CLO 프로젝트 파일명을 기준으로 만들어진 상위 폴더를 찾습니다. 5. 런웨이 애니메이션 작업에서는 Avatar Cache로 저장된 아바타 Geometry Cache와 Garment Cache로 저장된 의상 Geometry Cache를 각각 찾습니다. 6. Joint Animation을 시험한 경우에는 Skeletal Mesh와 Animation Sequence가 별도로 생성될 수 있지만, 이번 수업에서는 이 Asset을 메인 런웨이 재생에 사용하지 않습니다. 7. LiveSync Save가 끝났다고 Level Sequence 작업까지 끝난 것은 아닙니다. 다음 저널에서 Level Sequence를 직접 만들고 아바타와 가먼트 Geometry Cache를 Track으로 추가합니다. 8. Asset 저장을 확인한 뒤 임시 확인용 UsdStageActor는 삭제해도 됩니다. 9. Content Browser에서 Save All을 실행합니다.

8. 수정 후 다시 보내는 기본 루프

CLO 수정 → CLO 프로젝트 저장 → Unreal LiveSync Mode에서 Update → Viewport 확인 → 결과가 확정되면 Save 순서로 반복합니다. Update를 누를 때마다 새 Asset이 무한히 생기는 것은 아닙니다. Update는 현재 UsdStageActor를 갱신하는 확인 단계이고, Save는 Unreal에서 사용할 Asset을 지정 폴더에 만드는 단계입니다. 이미 Sequencer에 배치한 Asset을 다시 Save할 때 이름이나 저장 폴더를 바꾸면 기존 Track의 연결이 끊길 수 있습니다. 수업 중에는 같은 프로젝트명과 같은 저장 폴더를 유지합니다.

연결되지 않을 때 확인 순서

1. CLO 한 개와 Unreal Editor 한 개만 실행 중인지 확인합니다. 2. CLO, Unreal과 LiveSync 버전 조합을 확인합니다. 3. CLO 설정에서 LiveSync가 활성화되어 있는지 확인합니다. 4. Unreal Plugins에서 LiveSync와 Substance 플러그인이 활성화되어 있는지 확인합니다. 5. CLO에서 패턴을 클릭해 연결 신호를 다시 발생시킵니다. 6. Unreal LiveSync Mode의 Connection Status를 다시 확인합니다. 7. Unreal 프로젝트를 저장한 뒤 CLO를 먼저 재시작하고, 필요하면 Unreal도 다시 시작합니다. 8. 전송이 50% 등 특정 구간에서 멈추면 계속 반복하지 말고 버전 호환표와 로그를 확인합니다. 9. 재질만 다르면 렌더러 차이를 고려하고 Base Color·Normal·Roughness·Metallic·Opacity 맵이 생성됐는지 확인합니다. 10. 문제 화면과 버전 정보를 캡처한 뒤 담당자에게 전달합니다.

다음 저널로 넘어가기 전 체크

□ Connection Status가 초록색입니다. □ CLO 의상과 아바타가 Unreal Viewport에 같은 크기와 포즈로 보입니다. □ 정지 포즈 또는 애니메이션을 Update로 확인했습니다. □ Save한 Asset 폴더를 찾았습니다. □ 애니메이션 작업이면 아바타 Geometry Cache와 가먼트 Geometry Cache를 각각 확인했습니다. □ Joint Animation은 수업 기본 경로에서 제외했습니다. □ 아직 Level Sequence를 만들지 않았으며 다음 단계에서 직접 구성한다는 것을 알고 있습니다. □ Unreal 프로젝트와 Asset을 Save All 했습니다. 이제 LiveSync 연결은 끝났습니다. 다음 저널에서는 저장된 아바타와 가먼트 Geometry Cache를 Level Sequence에 넣고, 카메라와 Camera Cuts를 만든 뒤 Movie Render Queue로 출력합니다.
