# StudioCats Manager

고정된 StudioCats 사이트 레이아웃은 유지하고, 포트폴리오·Apps·Journal 내용만 관리하는 로컬 도구다. 로그인/외부 CMS 없이 이 저장소 안의 JSON·이미지·정적 HTML을 다룬다.

## Run

```powershell
npm install
npm run dev
```

`http://127.0.0.1:5173/`을 열면 된다. 작업 중인 초안은 `content/portfolio.json`에 자동 저장되고, 브라우저 임시 사본도 같이 남긴다.

- 포트폴리오 프로젝트 추가, 선택, 편집, 삭제
- 앱 외부 링크·배포처·가격·플랫폼·대표 이미지 관리
- 저널 글과 문단/소제목/이미지/YouTube/링크/코드 블록 관리
- 이미지 파일을 `uploads/portfolio/`, `uploads/apps/`, `uploads/journal/`로 복사
- 갤러리 순서 변경과 대표 썸네일 한 장 지정
- BOOTH 외부 링크와 YouTube URL 저장
- “사이트 파일 생성”으로 카테고리 목록, 프로젝트 상세 HTML, sitemap.xml 생성
- 데스크톱/모바일 카드 미리보기

## 공개 흐름

1. 원하는 메뉴에서 새 항목을 만들고 내용·이미지·링크를 채운다.
2. `공개하기` 또는 `사이트 파일 생성`을 누른다.
3. 생성 결과를 확인한 뒤 `GitHub에 커밋 및 push`를 누른다. 이 버튼은 포트폴리오 데이터·이미지·생성된 페이지 파일만 커밋한다.

포트폴리오 샘플 카드에는 `demo: true`가 들어 있어 절대 사이트에 생성되지 않는다. Apps 4개는 기존 공개 데이터를 옮긴 실제 항목이고, Journal은 첫 글을 공개할 때까지 기존 준비중 페이지를 유지한다.

## 안전장치

- 공개를 눌러도 GitHub에 자동 push하지 않는다. 먼저 생성된 파일을 확인할 수 있다.
- 이미지 항목을 지워도 업로드 원본 파일은 자동으로 삭제하지 않는다.
- 공개 상태의 프로젝트에는 이미지가 최소 한 장 필요하다.
