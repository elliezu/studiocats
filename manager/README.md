# StudioCats Manager MVP

포트폴리오 콘텐츠를 고정된 사이트 레이아웃에 맞춰 관리하는 React/Vite UI MVP다.

## Run

```powershell
npm install
npm run dev
```

브라우저의 localStorage에 초안을 자동 저장한다. 이 단계에서는 다음을 검증한다.

- 프로젝트 추가, 선택, 편집, 삭제
- 대표 썸네일 한 장 지정
- 이미지 추가, 삭제, 드래그 순서 변경
- BOOTH 외부 링크와 YouTube URL 저장
- 데스크톱/모바일 반응형 미리보기

정적 HTML 생성과 GitHub Pages 배포 연결은 다음 단계다. 현재 공개된 홈페이지 HTML은 이 MVP에서 변경하지 않는다.
